# Project rules

## Writing style
- No em dashes (—) anywhere in content. Use a regular hyphen (-) instead.
- No ellipsis character (…). Write "..." if needed.

## Git commits
- Do not add "Co-Authored-By" or any Claude attribution lines to commit messages.

## Content
- "short" not "small" when referring to height.
- Do not reveal Linda's personal struggles in public-facing content. Keep egalitarian arguments universal.
